## 🛠️ Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, DaisyUI
- **State Management:** React Context API
- **UI & Notifications:** React Toastify
- **Deployment:** Vercel

---

## ✨ Key Features

1. **Interactive Exercise Library & Fast Fetching:** Browse a comprehensive list of exercises with detailed duration, calorie, and rating metrics. Built with smooth loading animations during data fetching for an optimal user experience.
2. **Dynamic My Plan Statistics:** Automatically calculates real-time summary metrics (Total Exercises, Total Minutes, Total Calories) that dynamically update whenever workouts are added, completed, or removed.
3. **Flexible Sorting & Filtering:** Easily re-sort workouts in your daily plan or saved list by **Duration**, **Calories**, or **Ratings** using a custom interactive dropdown.
4. **Custom Daily Planner & Saved List:** Seamlessly switch between **Today's Plan** and **Saved Workouts**, toggle exercise completion status, or clear finished lifts on the fly.
5. **Robust Route & Deployment Handling:** Fully equipped with a custom-styled 404 error page for invalid routes and optimized image loading patterns to ensure error-free reloads post-deployment.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites

Make sure you have Node.js (v18 or higher) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/antarindra/fitlog.git](https://github.com/antarindra/fitlog.git)
   cd fitlog
   ```

2. **Install dependencies:**
   **Bash**

   ```
   npm install
   ```
3. **Run the development server:**
   **Bash**

   ```
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000?utm_source=gemini) in your browser to view the application.
